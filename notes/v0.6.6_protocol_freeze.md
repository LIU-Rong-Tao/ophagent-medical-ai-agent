# v0.6.6 实验协议冻结记录

## 1. 目的

本记录用于冻结 v0.6.6 当前阶段的预审风险排序规则、评价基线、Top-K 复核比例和主要指标，避免后续根据 APTOS2019 测试集结果继续调整规则，造成后验调参或 analysis leakage。

当前 APTOS2019 六个 backbone 结果均定位为探索性实验（exploratory analysis），用于建立候选风险信号、评价协议和外部验证准备。

后续医院真实模型输出应作为外部验证（external validation / confirmatory validation）来源。医院数据到来前，不再根据 APTOS 测试集表现修改当前主实验规则。

## 2. 冻结的风险分数公式

当前 `pre_review_risk_score` 由 `scripts/build_pre_review_risk_table.py` 计算，只使用模型输出信号，不使用真实标签、预测正确性或错误类型。

### 2.1 Margin 规则

- `margin < 0.15`：加 2 分，原因记为 `low_margin_boundary`
- `0.15 <= margin < 0.30`：加 1 分，原因记为 `moderate_margin_boundary`

### 2.2 Entropy 规则

- `entropy_norm >= 0.75`：加 2 分，原因记为 `high_entropy`
- `0.60 <= entropy_norm < 0.75`：加 1 分，原因记为 `moderate_entropy`

### 2.3 DR 有序等级相关规则

该规则仅适用于 APTOS2019 / DR 五级有序分级任务。

- `pred_grade <= 2` 且 `severe_prob_mass >= 0.25`：加 3 分，原因记为 `potential_severe_undergrading_signal`
- `pred_grade <= 2` 且 `0.15 <= severe_prob_mass < 0.25`：加 2 分，原因记为 `weak_severe_undergrading_signal`

其中：

`severe_prob_mass = prob_Severe DR + prob_Proliferative DR`

该值只由模型输出概率计算，不使用真实标签。

### 2.4 Top-2 更高等级规则

该规则仅适用于 APTOS2019 / DR 五级有序分级任务。

- `top2_grade > pred_grade` 且 `top2_confidence >= 0.20`：加 2 分，原因记为 `second_choice_more_severe`
- `top2_grade > pred_grade` 且 `0.10 <= top2_confidence < 0.20`：加 1 分，原因记为 `weak_second_choice_more_severe`

### 2.5 高置信但边界接近规则

- `confidence >= 0.60` 且 `margin < 0.25`：加 1 分，原因记为 `confident_but_close_decision`

## 3. 冻结的风险等级阈值

- `pre_review_risk_score >= 5`：`high`
- `3 <= pre_review_risk_score < 5`：`medium`
- `pre_review_risk_score < 3`：`low`

## 4. 冻结的排序键

当前 `review_priority_rank` 按以下顺序生成：

1. `pre_review_risk_score` 降序
2. `entropy_norm` 降序
3. `confidence` 降序
4. `case_id` 升序

说明：

- `case_id` 升序是为了解决完全同分样本在输入顺序打乱后出现的 rank 不稳定问题。
- 该 tie-breaker 不改变任何样本的 `pre_review_risk_score`、`pre_review_risk_level` 或 `risk_reasons`。
- `confidence` 降序作为第三排序键不是标签泄漏，但与一般 failure detection 中“低置信更可疑”的直觉不完全一致。后续如需调整，应作为敏感性分析或新版本实验记录，不得直接覆盖当前 v0.6.6 主结果。

## 5. 冻结的 Top-K 复核比例

后续标准 Failure Detection / Selective Prediction 指标补充阶段，固定评估以下复核比例：

- Top 5%
- Top 10%
- Top 20%
- Top 30%

其中 Top 20% 可作为主要展示点之一，但不得根据结果改动 Top-K 设置。

## 6. 冻结的 baseline 方法

后续标准指标比较中，固定包含以下方法：

1. `random_expected`
   - 理论随机抽查期望。

2. `random_mc`
   - Monte Carlo 随机抽查结果，用于估计随机基线波动。

3. `confidence_only`
   - 低 `confidence` 优先。
   - 等价风险分数可记为 `1 - confidence`。

4. `margin_only`
   - 小 `margin` 优先。
   - 等价风险分数可记为 `-margin` 或按 margin 升序排序。

5. `entropy_only`
   - 高 `entropy` 或 `entropy_norm` 优先。

6. `uncertainty_rank_fusion`
   - 基于 confidence、margin、entropy 的排序融合。
   - 该方法用于评估简单不确定性信号融合是否比单指标更稳健。

7. `ophagent_combined`
   - 当前 `pre_review_risk_score` 对应的规则组合方法。

如新增以下方法，应作为后续扩展实验，不纳入当前 v0.6.6 冻结主协议：

- TTA variance
- ensemble disagreement
- image quality score
- embedding / domain distance
- learned auditor
- doctor-defined cost score
- report-evidence consistency score

## 7. 冻结的主要评价指标

### 7.1 主要指标

后续补充标准指标时，优先报告：

- `AUROC-Error`
- `AUPR-Error`
- `Risk-Coverage Curve`
- `AURC`
- `Top-K Error Precision`
- `Top-K Error Recall`
- `Top-K Error Lift / Enrichment`

其中 Top-K 默认覆盖：

- Top 5%
- Top 10%
- Top 20%
- Top 30%

### 7.2 次要指标

可作为补充报告：

- 剩余自动处理样本错误率
- risk group error rate
- low-risk NPV
- per-class error recall
- per-class review fraction
- high-confidence error analysis
- bootstrap confidence interval

bootstrap 后续如加入，应优先按 patient / exam / volume 级别抽样；若当前 APTOS 只具备 image-level 信息，则明确标注为 image-level bootstrap。

## 8. severe underestimation 的当前地位

`severe underestimation` 暂不作为当前标准 Failure Detection 主分析指标。

当前主分析先聚焦：

- general error detection
- error enrichment
- selective prediction
- review prioritization under fixed budget

DR 方向敏感错误分析作为后续专项分析保留。

若后续继续分析 severe underestimation，其定义固定为后验评价字段：

- `true_grade >= 3`
- `pred_grade < 3`

该定义只用于评价，不参与排序阶段。

该定义仅适用于 DR 有序等级任务。若未来医院任务为 CSC / ERM / MH / RAO / RD / VKH 等非天然有序六分类任务，不得直接迁移该定义，应改为：

- disease-pair-sensitive misclassification analysis
- urgency tier analysis
- 或由医生定义 clinical cost matrix

## 9. 当前冻结边界

自本记录之后，不应再根据 APTOS2019 测试集结果调整：

- `pre_review_risk_score` 公式
- `pre_review_risk_level` 阈值
- 排序键
- Top-K 复核比例
- baseline 方法集合
- primary metrics
- severe underestimation 定义

如必须修改，应另开版本并明确标记为新的探索性实验，不得与当前 v0.6.6 主结果混用。

## 10. 尚未覆盖的实验风险

本协议冻结记录不代表全链路实验泄漏审计完成。尚未覆盖：

- 上游模型训练/验证/测试划分是否存在泄漏
- checkpoint 是否根据 test set 选择
- test set 是否参与阈值或超参数选择
- 是否存在重复或近重复图像跨 train/test
- 医院数据预测单位是否为 slice / volume / eye / exam / patient
- OCT 场景下是否存在 slice-level / volume-level / patient-level leakage
- 医生定义临床代价矩阵的一致性和可解释性

## 11. 一句话结论

v0.6.6 当前冻结的主分析目标是：在无真实标签参与排序的前提下，评估眼科模型输出信号是否能支持低侵入式 general failure detection 与固定复核预算下的错误富集。severe underestimation、医生代价矩阵、learned auditor 和报告证据一致性均作为后续扩展，不进入当前冻结主分析。

  --class-to-idx experiments/aptos_convnext_tiny/lr1e-4_bs32_seed42/configs/class_to_idx.json \

第一次 target layer 用：
model.stages[-1].blocks[-1].norm
结果出现竖条纹，明显不正常。

后面打印 ConvNeXt 结构，确认每个 block 有 conv_dw。
改为：
model.stages[-1].blocks[-1].conv_dw
竖条纹消失，但 heatmap 很块状，定位区分度弱。

再改为：
model.stages[2].blocks[-1].conv_dw
分辨率稍高，但在 No DR 图上依然效果不好，热力图关注区域很散。

当前判断：
- Grad-CAM pipeline 已经跑通
- 现在问题是可视化效果不好
- No DR 图本身没有明显病灶，不适合作为判断 Grad-CAM 好坏的样例
- ConvNeXt 最深层 feature map 分辨率低，Grad-CAM 天然容易块状
- 下一步应该优先在 Moderate / Severe / PDR 图上测试
- 需要批量跑 demo_samples 每类 3 张，筛选 good / failure / interesting cases
- 不要急着集成 Streamlit，先把命令行 Grad-CAM 效果调稳定

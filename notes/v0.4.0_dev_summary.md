# v0.4.1 补充

## 新增内容

- 增加 Swin-Tiny baseline
- 增加统一 evaluation schema
- 增加 backbone comparison summary

## Summary Builder 更新

`build_experiment_summary.py` 现在统一读取：

- `logs/summary.json`
- `evaluation/test/metrics.json`

不再依赖：

- `checkpoint_meta.json`

## Benchmark 对比结果

在相同 APTOS2019 protocol 下：

| Backbone | Test Accuracy | Macro F1 | Weighted F1 |
|---|---:|---:|---:|
| ConvNeXt-Tiny | 0.8136 | 0.6496 | 0.8093 |
| Swin-Tiny | 0.8291 | 0.6567 | 0.8202 |

## 当前结论

在当前单 seed 实验中：

- Swin-Tiny 略高于 ConvNeXt-Tiny
- Macro F1 与 Weighted F1 均有小幅提升

但当前仍然属于 single-seed comparison，尚未形成完整 benchmark。

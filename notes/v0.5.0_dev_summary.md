## 当前 benchmark 结构

- Swin-Tiny

- ViT-B/16 official-like reference
- ViT-L/16 official-like
- RETFound-MAE-CFP official-like

## 当前 benchmark 结果

### Lightweight Baselines

| Backbone | Accuracy | Macro-F1 | Weighted-F1 | QWK |
|---|---:|---:|---:|---:|
| ConvNeXt-Tiny | 0.814 | 0.650 | 0.809 | 0.862 |
| Swin-Tiny | 0.829 | 0.657 | 0.820 | 0.898 |
| ViT-B/16 | 0.818 | 0.646 | 0.814 | 0.876 |

### Official-like Comparison

| Backbone | Accuracy | Macro-F1 | Weighted-F1 | QWK |
|---|---:|---:|---:|---:|
| ViT-B/16 official-like | 0.799 | 0.567 | 0.778 | 0.829 |
| ViT-L/16 official-like | 0.801 | 0.569 | 0.783 | 0.860 |
| RETFound-MAE-CFP official-like | 0.804 | 0.583 | 0.789 | 0.866 |

---

## 当前观察

- Swin-Tiny 仍是当前最强 lightweight baseline
- ViT-B/16 lightweight baseline 已接近 ConvNeXt-Tiny 与 Swin-Tiny
- ViT-B/16 到 ViT-L/16 的 official-like 提升有限
- 在 backbone scale 对齐后，RETFound-MAE-CFP 相比 ViT-L/16 official-like 存在小幅稳定增益
- Severe DR 在所有 backbone 上仍表现较差，主要瓶颈可能来自 class imbalance、hardcase scarcity 与 ordinal ambiguity

当前结果仍基于 single-run / seed=42，更适合作为 representation behavior analysis 与 benchmark infrastructure validation，而不是统计显著性结论。

# v0.5.3 CAM Adapter Foundation

## 新增内容

- 增加统一 CAM adapter，用于支持 ConvNeXt、Swin、ViT-B、ViT-L 与 RETFound 的 CAM 可视化流程
- 将 ConvNeXt 的 CNN stage target layer 与 Transformer 的 relative block depth target layer 统一到同一套接口
- 增加 `method × target layer/depth × smoothing` 的 CAM grid generation 流程
- 基于代表性眼底图像进行 qualitative lesion-alignment sanity check

---

## 当前 CAM target layer 结构

### CNN backbone

- ConvNeXt-Tiny 使用 stage-based target layer
- 当前支持 `stage2`、`stage3`、`stage4`

### Transformer backbone

- Swin / ViT / RETFound 使用 relative block depth
- 当前支持 `early`、`middle`、`late`

需要注意的是，Transformer 的 `early / middle / late` 只是为了统一跨 backbone 可视化接口而引入的工程归一化方式，并不表示 Transformer block 与 CNN stage 在结构上完全等价。

---

## Selected qualitative CAM settings

| Backbone | Selected CAM Setting |
|---|---|
| ConvNeXt-Tiny | `gradcam_stage3_eigen` |
| Swin-Tiny | `hirescam_middle_none` |
| ViT-B/16 lightweight | `gradcam_middle_eigen` |
| ViT-B/16 official-like | `layercam_middle_eigen` |
| ViT-L/16 official-like | `hirescam_middle_eigen` |
| RETFound-MAE-CFP | `hirescam_early_eigen` |

---

## 当前观察

在代表样本 `demo_samples/cmoderatedr/d9bbdc33db83.png` 上，ConvNeXt 的 CAM 与中央偏右黄白色渗出样区域对齐相对最清晰。

Swin、ViT 与 RETFound 可以通过统一 CAM adapter 生成可视化结果，但部分 CAM 仍存在热区弥散、边缘伪影、非病灶区域激活或可读性不稳定的问题。

因此，v0.5.3 的结果仅作为 qualitative lesion-alignment sanity check，不作为正式 explanation faithfulness 或 clinical localization 结论。

---

## 下一阶段

v0.6.0 将进入 Explainability Consistency Benchmark，重点从“能否生成 CAM”转向“CAM 是否稳定、合理、可复现”。

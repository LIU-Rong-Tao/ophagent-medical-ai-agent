# OphAgent v0.6.6：预审风险排序设计说明

本文档用于说明 v0.6.6 预审风险排序实验的设计边界、输入字段、排序规则、后验验证方式和阶段结论。

说明：该文档为 v0.6.6 明线合并后的重建版，用于替代 sanitize 阶段被删除或裁剪的早期设计说明。最终冻结依据以 `notes/v0.6.6_protocol_freeze.md`、`notes/v0.6.6_leakage_audit.md` 和 `notes/v0.6.6_error_detection_results.md` 为准。

## 1. 问题定义

v0.6.6 关注的问题是：

在真实标签不参与排序的前提下，能否仅根据模型输出信号，为人工复核生成优先级队列，并在后验评估中验证该队列是否能够富集错误样本。

需要区分两个阶段：

- 排序阶段：不使用真实标签、正确性字段、错误类型或后验临床标签；
- 后验评估阶段：使用真实标签计算错误发现能力和选择性复核指标。

因此，本阶段不是训练新的分类模型，也不是证明某个新风险分数最优，而是构建一个面向眼科模型输出的低侵入式预审排序与 general failure detection 评估框架。

## 2. 输入字段与排序约束

排序输入来自模型推理输出表，主要包括：

- `case_id`
- `pred_label`
- `confidence`
- `top2_label`
- `top2_confidence`
- `margin`
- `entropy` 或 `entropy_norm`
- 各类别预测概率

排序阶段禁止使用：

- `true_label`
- `correct`
- `is_error`
- `error_type`
- `severe_underestimate`
- 任何由真实标签推导出的后验字段
- 能直接泄露类别信息的路径字段

真实标签只允许在后验评估阶段使用。

## 3. 预审风险信号设计

v0.6.6 的预审信号主要来自模型输出分布，包括：

- 低置信度：模型 top-1 概率较低；
- 小 margin：top-1 与 top-2 类别概率接近；
- 高 entropy：预测分布不集中；
- top-2 更高等级：在 DR 有序等级任务中，第二候选类别比预测类别更重；
- severe probability mass：在 DR 有序等级任务中，重症相关类别概率质量较高。

这些信号用于生成预审排序分数和解释原因，但不引入真实标签。

## 4. 风险等级与排序规则

v0.6.6 输出每个样本的：

- `pre_review_risk_score`
- `pre_review_risk_level`
- `risk_reasons`
- `review_priority_rank`

冻结后的排序原则为：

1. `pre_review_risk_score` 降序；
2. `entropy_norm` 降序；
3. `confidence` 降序；
4. `case_id` 升序。

加入 `case_id` 的目的，是保证输入样本顺序被打乱时，完全并列样本仍然得到稳定排序。

## 5. 后验验证指标

v0.6.6 的后验验证只针对 general error detection，即：

- `is_error = pred_label != true_label`

本阶段使用的主要指标包括：

- AUROC-Error；
- AUPR-Error；
- Top-K Error Precision；
- Top-K Error Recall；
- Top-K Error Lift；
- Risk-Coverage；
- AURC。

对比方法包括：

- random expected；
- random Monte Carlo；
- 1-MSP / confidence-only；
- margin-only；
- entropy-only；
- uncertainty rank fusion；
- OphAgent combined。

其中 1-MSP、margin、entropy 和 uncertainty rank fusion 是经典不确定性强基线，不能被当作弱 baseline。

## 6. 完整测试集结果更新与阶段结论

在 APTOS2019 test split 的 1100 张样本上，v0.6.6 已完成 6 个 backbone / 配置的预审排序、强基线对比与后验验证。

本阶段新增了以下分析：

- 无真实标签参与排序的泄漏审计；
- sanitized rebuild 检查；
- 输入顺序打乱稳定性检查；
- random、1-MSP、margin、entropy、uncertainty rank fusion、OphAgent combined 等强基线对比；
- AUROC-Error；
- AUPR-Error；
- Top-K Error Precision / Recall / Lift；
- Risk-Coverage；
- AURC。

当前结果表明：

- 仅基于模型输出信号，可以对错误样本进行一定程度的富集；
- 经典不确定性信号，如 1-MSP、margin、entropy 和 uncertainty rank fusion，在多个 backbone 上表现稳定；
- 当前 OphAgent combined 规则并没有稳定超过上述经典强基线；
- 因此，v0.6.6 不应表述为“提出了最优风险排序器”，而应表述为“构建并冻结了一个面向眼科模型输出的预审排序、错误发现和选择性复核评估框架”。

因此，v0.6.6 的合理结论是：

> 模型输出信号能够支持低侵入式错误富集和选择性复核分析；但当前 OphAgent combined 规则没有稳定超过 1-MSP、margin、entropy 和 uncertainty rank fusion 等经典不确定性强基线。v0.6.6 的贡献应定位为一个经过泄漏审计和强基线验证的评估框架，而不是一个性能最优的新风险排序算法。

## 7. 与 v0.6.7 的边界

v0.6.6 不分析 clinical residual risk。

以下内容不属于 v0.6.6：

- 高置信错误；
- severe underestimation；
- undergrading / overgrading；
- clinical cost matrix；
- 医生定义的 dangerous misclassification；
- OCT urgency tier。

v0.6.7 将在冻结 v0.6.6 排序与 general failure detection 结果的基础上，进一步分析固定复核预算后自动放行区中残留的临床风险。

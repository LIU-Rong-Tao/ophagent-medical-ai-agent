# v0.7.1b 协议补全与图像聚类置信区间冻结说明

## 版本目标

v0.7.1b 只用于补全 v0.7.1 的证据链，不开启新方向，不引入新的解释性支线。

本版本不做：

- CAM
- SHAP
- attention map
- 其他与当前复核排序主线无关的 XAI 展示

本版本的目标是确认：v0.7.1 中观察到的 VTDR miss 富集，是否确实来自 severe-class probability mass 在预测等级 gate 之外提供的额外排序信息，而不是仅由 `pred_grade <= 2` 这个 gate 本身造成。

## 最终研究问题

在冻结 APTOS 模型、事件定义、复核预算和排序信号后，severe-class probability mass 是否能在预测等级 gate 之外，为外部 DR 数据中的 VTDR miss 提供额外复核排序信息？

## Primary Target

主目标：

- VTDR miss
- 定义：`true_grade >= 3 and pred_grade < 3`

主复核预算：

- Top20%

主比较：

- `gated_severe_prob_mass_only` vs `random gate-only`

主终点：

- 在每个外部数据集内，对 6 个 frozen backbone 的 Top20% event recall difference 做等权平均。

外部数据集分开报告：

- IDRiD_data
- MESSIDOR2

不把 IDRiD_data 和 MESSIDOR2 合并成一个总置信区间，因为它们是两个不同外部域。

## Gate-only Baseline 精确定义

令：

- `K = ceil(n * review_budget)`
- `E = {pred_grade <= 2}`

实现规则：

- 若 `|E| >= K`：从 `E` 中随机抽取 `K` 个样本；
- 若 `|E| < K`：先选择全部 `E`，再从非 `E` 中随机补足 `K - |E|` 个样本。

复核预算始终按全体样本数 `n` 计算，而不是按 eligible set 的大小计算。

Gate-only 回答的问题是：

> 只知道“模型预测未达重症”是否已经足够？severe-class probability mass 是否能在 eligible set 内进一步提供排序增量？

在 VTDR miss 任务中，`pred_le_2_only` 和 `eligibility_gate_only` 可能完全等价。若二者等价，只保留一个作为 random gate-only baseline，不把它们当作两个独立基线凑数。

## 随机基线与 Bootstrap 分开处理

### Random gate-only 估计

对 random gate-only 进行 2000 次重复随机抽样。

报告：

- mean
- 95% interval

### Image-clustered bootstrap

进行 2000 次图像级聚类 bootstrap。

规则：

- 按 dataset 分开 bootstrap；
- 抽样单位是 unique image；
- 同一图像对应的 6 条 backbone 记录必须一起进入 bootstrap sample；
- 每次 bootstrap 重新执行排序和 Top-K 选择；
- 方法差值定义为 `gated_severe_prob_mass_only - comparator`。

为了避免随机 gate-only 的抽样噪声污染方法差值 CI，bootstrap 内使用 gate-only 的期望值或固定随机种子策略。

## 主报告指标

主指标：

- event recall difference
- residual event count difference
- residual event rate difference
- 95% clustered bootstrap CI
- win rate

其中：

- `win rate = bootstrap 中 Δ > 0 的比例`

不要把 win rate 写成“成功概率”。

NPV 只能作为辅助指标，不能作为主要安全性结论。尤其 MESSIDOR2 的 VTDR miss 基础率较低，高 NPV 很容易被低事件率抬高。

## Learned Logistic 冻结规则

`learned_logistic` 只能在 APTOS 侧拟合，然后冻结到外部数据上推理。

以下内容必须全部来自 APTOS：

- feature columns 与顺序
- 缺失值处理策略
- `StandardScaler.mean_`
- `StandardScaler.scale_`
- logistic coefficients
- logistic intercept
- target-specific model

在 IDRiD_data / MESSIDOR2 上不得：

- 重新拟合；
- 重新选特征；
- 重新标准化；
- 根据外部结果调整阈值或排序信号。

否则就变成目标域适配，不再是 frozen external stress-test。

## Go / No-Go 判断规则

### 强证据

满足：

- 两个数据集差值点估计均为正；
- MESSIDOR2 的 95% CI 不跨 0；
- IDRiD_data 方向一致。

可写：

> 在外部压力测试中，severe-class probability mass 相比 random gate-only 为 VTDR miss 提供了额外复核排序信息。

### 中等证据

满足：

- 两个数据集点估计均为正；
- 但 IDRiD_data 因事件数较少，不确定性较大。

可写：

> 在两个外部数据集上观察到方向一致的增量趋势，但 IDRiD_data 的统计不确定性较大。

### 弱证据

出现：

- 两个数据集方向冲突；
- 或相对 random gate-only 无明确增量。

只能写：

> 观察到的富集主要可能来自预测等级 gate，当前 severe-class probability mass 的额外排序增量证据不足。

三种结果都可以展示，但只能改变结论强度，不能回头更换主指标。

## Demo 展示口径

展示中不要使用“自动放行区”。

统一使用：

- 未进入优先复核区的残余危险事件

病例页必须标注：

- 公共数据集回顾性 grade-based proxy 示例，不是患者级临床判断。

Demo 首页默认固定为：

- VTDR miss
- Top20%
- 两个外部数据集汇总

dataset、backbone、budget 选择器放入技术细节页，避免现场展示变成后台操作。

## 最终展示叙事

问题：

- 有限复核预算下，如何优先暴露危险漏检？

方法：

- 冻结模型和协议，仅利用输出概率进行事件特异排序。

验证：

- 外部域移压力测试，并与 random gate-only 和通用不确定性 baseline 比较。

结果：

- 报告捕获增量，也报告未进入优先复核区的残余危险事件。

边界：

- 公共数据；
- grade-only proxy；
- 非患者级临床判断；
- 非临床部署验证。

合作：

- 由医生定义真实风险事件；
- 由医生确认可接受复核预算；
- 在真实医院数据和真实模型输出上验证。

## Protocol deviation: learned_logistic external baseline

v0.7.0 原协议计划保留 `learned_logistic` 作为外部 secondary baseline。

当前 v0.7.1/v0.7.1b 已完成 primary gate-only comparison，但尚未实现 APTOS-frozen `learned_logistic` 的外部推理。因此，外部 `learned_logistic` baseline 记录为 secondary baseline 缺失 / protocol deviation。

该偏差不影响 v0.7.1b 的 primary comparison：`gated_severe_prob_mass_only` vs `random_gate_only_expected`。该主比较回答的是 severe-class probability mass 是否在预测等级 gate 之外提供额外排序信息。

后续如果补充外部 `learned_logistic` baseline，必须读取 APTOS 侧 frozen artifact，包括 feature order、missing value policy、StandardScaler 参数、logistic coefficients 和 intercept；不能在外部数据上重新拟合、重新标准化或重新选特征。

# v0.6.4 Real LLM Safety Probe Plan

## 版本定位

v0.6.4 在 v0.6.3 controlled real LLM provider 的基础上，进行小规模真实 LLM safety probe。

本版本目标不是评估医学报告质量，也不是证明系统具备临床安全性，而是初步观察真实 LLM 在 constrained prompt 下的报告草稿行为，并统计 RuleBasedSafetyChecker 的 pass / fallback / flagged claim 分布。

## 背景

v0.6.3 已完成：

- OpenAI-compatible real LLM provider
- `--report-provider real_llm`
- real_llm provider 离线测试
- renderer integration without network
- gpt-4o-mini 手动 smoke / summary run
- v0.6.3 real LLM summary artifacts

但 v0.6.3 只包含单次 summary run，缺少小规模 case set 上的真实输出行为统计。

因此 v0.6.4 需要补充：

- 多 case real LLM run
- safety pass / fallback 统计
- flagged claim type 分布
- API failure 记录
- 典型 pass / fallback 样例
- 初步 false negative / false positive notes

## 核心问题

v0.6.4 主要回答：

1. real_llm provider 在一批 case 上能否稳定运行？
2. constrained prompt 下，真实 LLM 是否仍会产生 unsafe overclaim？
3. RuleBasedSafetyChecker 拦截了哪些 claim type？
4. fallback 是否能在批量运行中稳定触发？
5. 是否出现明显漏检或误杀？
6. 这些结果是否足以支撑后续 integrated showcase？

## 非目标

v0.6.4 不做：

- 医学事实正确性评估
- 临床报告质量评估
- LLM-as-judge
- 多模型 benchmark
- 大规模统计显著性实验
- Web demo / deployment
- LoRA / SFT
- RAG / knowledge grounding

## 最小实验规模

优先使用小规模 pilot：

- 最低：5 个 case
- 推荐：10-20 个 case
- 如果数据准备不足，可先使用现有 demo / case artifacts 进行 pilot

本版本结果必须标注为 small-scale pilot，不得包装成统计性结论。

## 统计字段

`safety_probe_results.json` 应至少包含：

- total_cases
- success_count
- api_failure_count
- safety_pass_count
- fallback_count
- fallback_rate
- flagged_claim_type_counts
- provider
- provider_model
- provider_version
- checker_version
- safety_policy_version
- prompt_hash_available
- api_key_leakage_check
- sample_case_ids
- manual_notes

## 安全要求

- 不提交 API key
- 不提交完整敏感请求
- 不提交完整大规模 case artifact
- summary 产物必须检查 `contains_sk_key = False`
- real LLM 输出必须经过 RuleBasedSafetyChecker
- unsafe draft 必须 fallback 到 deterministic template report

## 面试解释口径

v0.6.4 应描述为：

- small-scale real LLM safety probe for guarded ophthalmology report drafting

不应描述为：

- clinical report generation benchmark
- full hallucination evaluation
- medically validated report generation
- production-grade safety system

更准确的说法是：

v0.6.4 在一批 case 上初步观察真实 LLM 输出进入 guarded workflow 后的 pass / fallback / flagged claim 行为，为后续 integrated showcase 和 v0.7 knowledge grounding / RAG 主线提供数据基础。

# v0.7.1 外部 DR 直接推理与复核排序说明

## 版本定位

v0.7.1 基于 v0.7.0 冻结的 external DR protocol，使用 APTOS-trained frozen checkpoints 在 IDRiD_data / MESSIDOR2 test split 上进行 direct external inference，并进一步评估复核排序信号在外部数据上的错误富集能力。

本版本不使用 IDRiD_data / MESSIDOR2 train 或 val 训练模型，不根据外部结果重新选择 primary target、ranking signal 或 review budget。

因此，v0.7.1 应被解释为：

- external frozen-checkpoint direct inference；
- external error enrichment analysis；
- residual risk analysis。

不应被解释为：

- 外部数据重训；
- 临床部署验证；
- 分类模型已充分泛化后的临床结论。

## 输入

主要输入文件：

- `experiments/summary/v0_7_0/external_dr_dataset_inventory.csv`
- `experiments/summary/v0_7_1/external_dr_direct_inference_predictions.csv`

使用的外部 test split：

- `IDRiD_data/test`
- `MESSIDOR2/test`

使用的 frozen backbones：

- `convnext_tiny`
- `swin_tiny`
- `vit_b_imagenet`
- `vit_b_official_like`
- `vit_l_official_like`
- `retfound_mae_cfp_official_like`

## 外部分类迁移结果

外部直接推理显示模型存在明显域迁移压力。

IDRiD_data 上最高 accuracy 为 0.4563，最高 QWK 约 0.5835。MESSIDOR2 上 accuracy 约 0.56–0.61，但 macro-F1 仅约 0.27–0.33，且多模型预测分布明显偏向 0 类。

因此，后续复核排序结果必须在分类迁移不足的背景下解释，不能包装为分类器充分泛化后的临床验证。

## 复核排序事件定义

本版本沿用 v0.6.x / v0.7.0 冻结口径：

- `large_undergrading = true_grade - pred_grade >= 2`
- `vision_threatening_dr_miss = true_grade >= 3 and pred_grade < 3`
- `dangerous_undergrading = large_undergrading OR vision_threatening_dr_miss`

## 冻结 ranking protocol

Primary target 1：

- target: `large_undergrading`
- ranking signal: `expected_gap_only`
- score: `expected_grade - pred_grade`
- primary budget: Top20%

Primary target 2：

- target: `vision_threatening_dr_miss`
- ranking signal: `gated_severe_prob_mass_only`
- score: `P(grade 3) + P(grade 4)` under `pred_grade <= 2`
- primary budget: Top20%

Secondary target：

- target: `dangerous_undergrading`
- role: composite supplementary target
- 不替代 primary targets。

## 主要发现

### large_undergrading

`expected_gap_only` 在 IDRiD_data / MESSIDOR2 上具有一定危险低估富集能力，但外部迁移不稳定。

Top20% 下：

- IDRiD_data：event recall 约 0.2778–0.5833，enrichment ratio 约 1.36–2.86。
- MESSIDOR2：event recall 约 0.2532–0.5065，enrichment ratio 约 1.26–2.51。

结论：`expected_gap_only` 对 large_undergrading 仍优于随机复核，但外部稳定性弱于 vision-threatening miss 目标。

### vision_threatening_dr_miss

`gated_severe_prob_mass_only` 在两个外部数据集上均表现出稳定的重症漏检富集能力。

Top20% 下：

- IDRiD_data：event recall 约 0.3750–0.6957，enrichment ratio 约 1.84–3.41。
- MESSIDOR2：event recall 约 0.7586–0.8889，enrichment ratio 约 3.76–4.41。
- MESSIDOR2 上 low-risk NPV 约 0.9833–0.9929。

结论：即使 frozen checkpoints 在外部分类迁移上存在压力，`gated_severe_prob_mass_only` 仍能稳定富集 vision-threatening miss。这是 v0.7.1 最强的外部错误富集证据。

## 解释边界

v0.7.1 支持的结论是：

> 在 frozen APTOS checkpoints 外部迁移存在压力的背景下，severity-aware review ranking signal 仍能对部分危险错误进行富集，尤其是 vision-threatening miss。

v0.7.1 不支持的结论是：

> 模型已经完成临床泛化验证，可以直接部署。

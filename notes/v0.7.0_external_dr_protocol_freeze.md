# v0.7.0 外部 DR 验证协议冻结

## 版本定位

v0.7.0 是 OphAgent 从 APTOS 内部方法开发转向外部 DR 数据验证的起点。

本版本不根据 IDRiD / MESSIDOR2 的结果重新选择方法，只冻结 v0.6.x 阶段已经得到的审计协议，并进行外部数据 precheck。

## 当前研究边界

v0.6.x 阶段的结论限定在：

- APTOS 数据集；
- 多 backbone prediction records；
- grade-based risk proxy；
- 眼底 DR 五分类标签体系。

当前结论不能直接解释为已经发现真实临床机制，也不能直接等价于患者级临床终点。

## Primary targets

v0.7.0 冻结以下 primary targets：

1. `large_undergrading`
   - 定义：模型预测等级显著低于真实等级。
   - 作用：捕捉方向敏感的严重低估错误。

2. `vision_threatening_dr_miss`
   - 定义：真实等级达到威胁视力 DR 代理阈值，但模型预测未进入高风险等级。
   - 作用：捕捉威胁视力 DR 漏检相关错误。

## Secondary target

保留 `dangerous_undergrading` 作为 secondary composite target。

它不作为唯一主目标，只用于观察合成危险低估场景下不同排序信号的趋势。

## 主复核预算

主预算冻结为：

- Top20%

补充预算：

- Top10%
- Top30%

主结论优先基于 Top20%，Top10% / Top30% 只作为敏感性补充。

## 主排序信号

针对不同 primary target 冻结不同主信号：

| Target | 主排序信号 | 理由 |
|---|---|---|
| `large_undergrading` | `expected_gap_only` | v0.6.8b 中在 Top20% 下更稳定 |
| `vision_threatening_dr_miss` | `gated_severe_prob_mass_only` | v0.6.8b 中在 Top20% 下更稳定 |

## Supervised baseline

保留 `learned_logistic` 作为监督式复核排序 baseline。

v0.7.0 采用简单冻结方式：

- 在全部 APTOS prediction records 上拟合一个 final Logistic Regression；
- 特征集合沿用 v0.6.8；
- 使用 L2 Logistic Regression；
- `class_weight=balanced`；
- `decision_function` 作为 learned review score；
- 不解释为校准概率。

## Diagnostic baselines

由于 risk proxy 和排序信号存在结构性耦合，v0.7.0 必须加入诊断基线，用来拆分 gate 本身和概率质量带来的增益。

新增诊断基线：

1. `pred_le_2_only`
   - 检查仅使用预测等级是否落在非重症区间的效果。

2. `pred_grade_ascending`
   - 检查仅按预测等级从低到高排序的效果。

3. `eligibility_gate_only`
   - 检查与 target 定义相关的 gate 本身能解释多少排序收益。

这些基线不作为主方法，只用于机制审计和防止过度声称。

## 外部数据候选

v0.7.0 只做 precheck，不做最终外部验证。

候选数据集：

- IDRiD
- MESSIDOR2

precheck 内容：

1. 类别目录是否完整；
2. train / val / test 是否存在；
3. 每个 split 的类别分布；
4. test split 中 severe / proliferative 样本数；
5. 是否可以构造 grade-only RDR / VTDR proxy；
6. 是否存在重复图像或疑似泄漏风险；
7. 与 APTOS 预处理是否兼容；
8. 是否可以直接使用 APTOS frozen checkpoints 推理。

## 禁止事项

v0.7.0 禁止：

- 根据 IDRiD / MESSIDOR2 结果重新选择主排序信号；
- 根据外部结果修改 primary target；
- 根据外部结果调整 Top-K 主预算；
- 把目标数据重训结果称为 direct external validation；
- 把 grade-only proxy 说成真实临床终点。

## 后续版本规划

- v0.7.0：协议冻结与外部数据 precheck。
- v0.7.1：APTOS frozen checkpoints 在 IDRiD / MESSIDOR2 上的 direct external validation。
- v0.7.2：如 direct transfer 崩溃，再做目标数据重训后的 protocol reproduction。

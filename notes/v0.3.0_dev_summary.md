# Core Update

## Lightweight Agent Runner

v0.3.0 引入：

```text
agent/
  schema.py
  runner.py
  providers.py
```

当前 workflow：

```text
image
  ↓
run_agent(...)
  ↓
classification
  ↓
top-k prediction
  ↓
structured findings
  ↓
rule-based / OpenAI reasoning
```

实现：

- unified workflow
- reusable `run_agent(...)`
- provider abstraction
- reusable reasoning pipeline
- lightweight agent-style orchestration


---

## Structured Findings

新增：

```text
findings/
```

workflow：

```text
classification
  ↓
structured findings
```

当前 findings：

- 基于 classification prior
- 结合 explainability context
- 用于 workflow explanation
- 不作为 lesion detector 输出

---

## Rule-based / OpenAI Reasoning

支持：

```text
rule_based
openai
fallback provider
```

当前：

- 默认使用 rule-based report
- OpenAI report 可选生成
- Streamlit 中按钮触发
- 避免 rerun 重复 API 调用

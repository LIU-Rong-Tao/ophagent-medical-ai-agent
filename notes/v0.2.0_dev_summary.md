# Grad-CAM 调参结论

测试过：

- stage2 / stage3 / stage4
- gradcam / hirescam / eigencam / layercam
- smooth / no smooth

最终结论：

HiResCAM + stage3 + no smoothing

原因：

- 比 stage4 更细
- 比 stage2 更稳定
- 比普通 GradCAM 更贴近病灶区域
- smoothing 虽更平滑，但会降低定位可信度

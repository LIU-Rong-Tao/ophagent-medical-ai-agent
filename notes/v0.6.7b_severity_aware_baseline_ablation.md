# v0.6.7b Severity-aware Baseline Ablation

## 定位

v0.6.7b 是在 v0.6.7 clinical residual risk evaluation 之后进行的消融实验。

v0.6.7 中，ophagent_combined 在 large_undergrading 和 vision_threatening_dr_miss 等危险低估事件上表现有效。但这个结果还有一个关键追问：

ophagent_combined 的优势到底来自多信号组合，还是某些简单的 severity-aware signals 已经足够？

v0.6.7b 的目的就是拆解这一点。

## 输入

主要输入：

- experiments/summary/v0_6_7/clinical_event_cases.csv
- 各 backbone 的 test_predictions.csv

排序阶段只使用模型输出信号，不使用真实标签。真实标签和 clinical event labels 仅用于后验评估。

## 比较方法

v0.6.7b 比较了：

- ophagent_combined
- severe_prob_mass_only
- gated_severe_prob_mass_only
- expected_grade_only
- expected_gap_only
- top2_more_severe_only

其中：

- severe_prob_mass_only 使用 P(Severe) + P(PDR) 排序。
- gated_severe_prob_mass_only 只在 pred_grade <= 2 的样本中使用 P(Severe) + P(PDR) 排序。
- expected_grade_only 使用模型概率分布的期望严重等级排序。
- expected_gap_only 使用 expected_grade - pred_grade 排序。
- top2_more_severe_only 使用 top2_grade > pred_grade 及 top2_confidence 排序。

## 主要发现

v0.6.7b 的结论是：ophagent_combined 是有效的，但在加入更直接的 severity-aware baselines 后，它并不是危险低估任务上的最优排序规则。

在 Top20% 复核预算下：

- large_undergrading 中，expected_gap_only 表现最好，mean recall 为 66.1%，捕获 177 / 263 个样本；ophagent_combined 捕获 156 / 263 个样本。
- vision_threatening_dr_miss 中，gated_severe_prob_mass_only 表现最好，mean recall 为 75.9%，捕获 298 / 391 个样本；ophagent_combined 捕获 241 / 391 个样本。

这说明危险低估样本的富集能力主要来自模型输出中的严重程度感知信号，而不是完整的手工 combined 分数本身。

## 对 v0.6.7 的修正

v0.6.7 的原始故事线可以表述为：ophagent_combined 能够富集方向敏感危险错误。

v0.6.7b 对这个故事线进行了修正：ophagent_combined 有效，但更简单、更可解释的 severity-aware signals 可以更好地解释主要增益。

因此，项目价值不应被表述为某个手工 combined 分数最优，而应表述为：模型输出中存在可解释的临床严重程度信号，可以用于复核优先级排序。

## 后续

v0.6.7c 进一步把 severity-aware baselines 和传统 uncertainty baselines 放入统一比较框架，并通过 overlap analysis 和 residual profile 解释不同排序信号为什么有效、仍然漏掉什么。

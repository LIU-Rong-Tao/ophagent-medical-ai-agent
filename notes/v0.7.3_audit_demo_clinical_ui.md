# v0.7.3 Audit Demo Clinical UI

## 版本定位

本版本将 OphAgent 的 Streamlit demo 从早期分类/CAM 展示升级为面向模型输出审计的五页临床展示 demo。

本版本是科研展示与模型输出审计工作流 demo，不用于临床诊断、治疗建议或真实医疗决策。

## 主要新增功能

- 保持统一入口：`streamlit run app/demo.py`。
- 新增五页导航：
  - 项目概览；
  - 单病例审计；
  - 批量复核排序；
  - 外部证据；
  - 新任务审计沙盒。
- 新增“临床展示 / 研究审计”双模式：
  - 临床展示：优先展示临床可读结论、复核队列和风险解释；
  - 研究审计：展开技术字段、原始表格、JSON 和实验路径。
- 默认展示临床病例卡与红黄绿复核队列。
- 技术指标、英文代码和原始表默认折叠，仅在研究审计模式展开。
- 修复中文字体方框、数值遮挡、标签重叠和候选卡省略号问题。
- No DR / Mild DR 候选卡完整显示。
- 外部证据页保留 v0.7.1b / v0.7.2 冻结研究证据，不伪装成当前模型即时结果。

## 科研口径

本版本严格区分：

- 预审排序：不使用真实标签；
- 后验验证：仅在有参考标签时计算捕获率、残余风险和事件召回；
- 冻结研究证据：读取既有实验产物，不由页面即时重算覆盖。

## 边界说明

- 当前 demo 不用于临床诊断。
- prediction records 不等同于独立患者。
- APTOS 五级 DR 任务仅能覆盖 grade-based VTDR miss proxy，不包含 DME。
- 其他眼病 CSV 仅作为通用分类审计沙盒，不代表完整疾病专属审计协议。

## 验证

- 服务器测试：22 passed。
- 页面人工检查：五页可打开，临床展示/研究审计模式可切换，中文与图表显示正常。

# v0.7.2 Metric Sensitivity Audit

## 版本定位

本版本用于检查 OphAgent 预审复核排序结论是否依赖单一评价指标。

核心问题是：如果更换评价口径，事件特异风险排序方法是否仍然稳定优于普通不确定性或随机候选基线。

本版本仍属于公共数据回顾性实验，不用于临床诊断、治疗建议或真实医疗决策。

## 审计目标

- 目标事件：grade-based VTDR miss proxy。
- 复核阶段：模型输出后的预审排序与后验验证。
- 重点方法：`gated_severe_prob_mass_only`。
- 对照方法：随机候选、普通不确定性信号、其他排序规则。

## 评价口径

本版本比较多个评价指标：

- AURC；
- AUGRC；
- partial_AUGRC_70_90；
- Top20 event recall；
- AUROC error 等补充指标。

## 主要结果

在 IDRiD_data / MESSIDOR2 与六个 backbone 组合上：

- AURC：12/12 第一；
- AUGRC：12/12 第一；
- partial_AUGRC_70_90：12/12 第一；
- Top20 event recall：11/12 第一或并列第一。

## 解释

该结果说明：在当前冻结外部实验设置下，事件特异风险信号在多个评价口径下表现一致，不只是依赖单一 Top-K 指标。

## 边界说明

- 该结果表示跨评价口径的一致性，不等同于临床效用证明。
- prediction records 不等同于独立患者。
- VTDR miss 是 grade-based proxy，不包含 DME。
- 所有结论仍需在真实临床流程和医生复核中进一步验证。
